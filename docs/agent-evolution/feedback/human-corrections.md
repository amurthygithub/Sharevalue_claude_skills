# Human corrections

Append-only. When the user corrects an agent's behavior in a way that should change future behavior, paste the correction here verbatim with date + context.

Periodically scan this file for recurring corrections; promote those to [LESSONS_LEARNED.md](../LESSONS_LEARNED.md), then to [CLAUDE.md](../../../CLAUDE.md).

---

## Format

```
### YYYY-MM-DD — <skill or workflow>
**Correction (verbatim):** "<exact words>"
**Context:** <what the agent had just done>
**Applied:** <yes/no/in-progress — link to the skill/CLAUDE.md change if any>
```
