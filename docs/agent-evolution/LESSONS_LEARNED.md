# LESSONS_LEARNED

Promote learnings here when:
- A pattern recurs (>2 incidents)
- A correction from the user contradicts current behavior
- A skill produced a wrong answer that points at a fixable prompt issue

Once a lesson stabilizes, **promote it into [CLAUDE.md](../../CLAUDE.md)** so the rule lives where every future session sees it. Lessons here are staging; CLAUDE.md is canonical.

---

## Format

```
### YYYY-MM-DD — <one-line title>
**Skill / context:** <which skill or workflow exposed it>
**Observation:** <what happened>
**Rule:** <what to do differently>
**Promoted to CLAUDE.md?** <yes/no — section reference>
```
